# Security Policy

## Supported Versions
Enterprise-Agent-OS security updates are provided for the current master branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of Enterprise-Agent-OS and its hardware-enclave simulation seriously. If you discover a security vulnerability, please report it privately to ensure enterprise compliance and safe remediation.
